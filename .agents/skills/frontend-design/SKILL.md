# Frontend Design Skill

## Core Principles
1. **Design System Consistency**:
   - Curated corporate palette: Deep navy primary (`#0f213f`, `#162f59`), teal/cyan accents (`#0d9488`, `#0284c7`), semantic status colors (Emerald, Amber, Rose).
   - Typography: Clean sans-serif (`Plus Jakarta Sans` or `Inter`) paired with monospaced accents (`JetBrains Mono`) for IDs, timestamps, and codes.
2. **Component Structure**:
   - Keep components modular and single-responsibility.
   - Use clear accessibility patterns: ARIA roles, labels, and keyboard navigability.
3. **Responsive & Print-Friendly**:
   - Layouts must be responsive across Desktop, Tablet, and Mobile.
   - Provide `@media print` clean formatting for reports and records.
